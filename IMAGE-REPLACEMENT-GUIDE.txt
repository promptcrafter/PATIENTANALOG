PART 3: IMAGE PREPARATION
================================================================================

STEP 1: Optimize for Web Use
-----------------------------

Tool Options:
- Online: TinyPNG (https://tinypng.com/)
- Desktop: Adobe Photoshop, GIMP (free), Squoosh
- Command line: ImageMagick, JPEGoptim

Optimization Settings:
- Format: JPEG (maintain consistency with existing images)
- Resolution: 1920 x 1080 pixels (or 1920 x 1280)
- Quality: 80-85% (balance quality vs file size)
- Target File Size: < 500 KB (ideally 200-400 KB)
- Color Profile: sRGB

STEP 2: Test Appearance with Filters
-------------------------------------

Your website applies heavy filtering to background images:
- Opacity: 0.20 to 0.80
- Saturate: 0.5
- Brightness: 0.7

Test Command (using browser dev tools):
img { opacity: 0.2; filter: saturate(0.5) brightness(0.7); }

Ensure image still looks good when heavily filtered.

STEP 3: Crop and Aspect Ratio
------------------------------

Preferred Aspect Ratio: 16:9 (landscape)
Dimensions: 1920 x 1080 pixels (minimum)

Cropping Guidelines:
- Center the most interesting organoid structures
- Leave some negative space for text overlay
- Ensure key features visible even when heavily filtered

PART 8: TROUBLESHOOTING
================================================================================

ISSUE: New image doesn't appear after replacement
--------------------------------------------------
Solution:
1. Hard refresh browser (Ctrl+Shift+R / Cmd+Shift+R)
2. Clear browser cache
3. Check filename exactly matches (case-sensitive)
4. Verify file path is correct
5. Check file permissions (should be readable)

ISSUE: Image looks pixelated/blurry
------------------------------------
Solution:
1. Check source image resolution (needs to be high-res)
2. Verify optimization didn't over-compress (try 90% quality)
3. Ensure aspect ratio wasn't distorted during cropping
4. Use higher resolution source (at least 1920px wide)

ISSUE: Image file size too large (>500 KB)
-------------------------------------------
Solution:
1. Re-optimize with lower quality (try 75-80%)
2. Reduce resolution slightly (try 1600 x 900)
3. Use online compression tool (TinyPNG, Squoosh)
4. Crop to remove excess negative space

ISSUE: Attribution requirements unclear
----------------------------------------
Solution:
1. Email image source for clarification
2. Default to including attribution (safer)
3. Use different image with clear CC0/Public Domain
4. Contact publisher/author directly

ISSUE: Image doesn't work with site's color scheme
---------------------------------------------------
Solution:
1. Adjust image brightness/contrast before upload
2. Choose image with complementary colors
3. Test with site's filter effects before committing
4. Try different source image

APPENDIX A: VISUAL EXAMPLES OF CORRECT vs INCORRECT
================================================================================

CORRECT Brain Organoid Images Show:
✓ Round, spheroid blob-like structures
✓ 3D appearance (not flat)
✓ Size reference: 2-5mm diameter typical
✓ Culture context: In media, Matrigel, or culture dish
✓ Microscopy: Brightfield, phase contrast, or fluorescence
✓ Multiple organoids in field of view (often)
✓ Cross-sections: Reveal layered neural tissue structure
✓ Staining: May show red/green/blue immunofluorescence

INCORRECT Brain Images Show:
✗ Brain anatomy diagrams (labeled lobes, regions)
✗ Brain cross-sections (clinical/anatomical)
✗ Neuron illustrations or cartoons
✗ MRI/CT scan images
✗ Flat 2D cell culture
✗ Single neurons under microscope
✗ Brain surface imagery
✗ Clinical/medical imaging

Keywords That Indicate CORRECT Images:
- "organoid culture"
- "spheroid"
- "3D culture"
- "Matrigel"
- "immunofluorescence"
- "iPSC-derived"
- "self-organizing"

Keywords That Indicate INCORRECT Images:
- "anatomy"
- "cross-section" (unless organoid cross-section)
- "clinical imaging"
- "diagnostic"
- "patient scan"
- "neuroanatomy"
- "brain regions"
