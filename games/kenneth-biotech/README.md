# 🧬 Kenneth's AMAZING Biotech Adventure!

A fun, educational puzzle game where Kenneth builds incredible bio-systems by connecting organs, organoids, and high-tech components!

## ✨ Features

### 🎮 Gameplay
- **50+ Bio-Modules**: Real organs, lab-grown organoids, and futuristic tech
- **24+ Levels**: Across 4 exciting eras
- **6 Connection Types**: Neural, Vascular, Data, Energy, Fluid, Universal
- **15+ Synergies**: Discover special combos for HUGE bonuses
- **Combo System**: Up to 5x multipliers for quick play
- **6 Power-Ups**: Hints, Undo, Score Boost, Extra Time, Shuffle, Super Connect
- **25+ Achievements**: Unlock rewards as you master the game

### 🌟 ADHD/Autism-Friendly Design
- **HIGH CONTRAST colors** for visibility
- **SATISFYING animations** for every action
- **CLEAR visual feedback** (color-coded ports, glow effects)
- **PREDICTABLE patterns** (consistent animations)
- **CELEBRATORY moments** (confetti, fireworks, encouragement)
- **Reduced motion mode** option
- **No sudden changes** without warning

### 📚 Educational Content
- Learn about real organs and how they work
- Discover organoids - mini organs grown in labs
- Explore microphysiological systems (organs-on-chips)
- Fun facts with every module!
- Real science notes for curious minds

## 🎯 How to Play

1. **Drag modules** from the tray to the grid
2. **Connect matching ports** (colors) for bonus points
3. **Create synergies** by connecting related modules
4. **Build combos** by placing quickly
5. **Reach the target score** before time runs out
6. **Earn stars** to unlock new levels!

## 🚀 How to Run

### Option 1: Single File (Easiest!)
Just open `kenneths-biotech-adventure-complete.html` in any modern web browser!

### Option 2: Development Version
Open `index.html` from the `kenneth-biotech-adventure` folder. All files must be in the same directory.
