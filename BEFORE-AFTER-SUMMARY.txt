HOW IT WAS DONE
---------------
Created automated Python script (fix-opacity-simple.py) that:

1. Scanned all 554 HTML files
2. Found opacity values below 0.60
3. Increased them by +0.35 (capped at max 0.85)
4. Applied changes safely without breaking the site

Formula: new_opacity = min(0.85, old_opacity + 0.35)

TECHNICAL DETAILS
-----------------
Script used regex pattern: opacity:\s*(0\.\d+)

Example transformations:
- 0.10 → 0.45 (cookie consent backgrounds)
- 0.18 → 0.53 (lab overlays)
- 0.20 → 0.55 (section header images) ← MOST COMMON
- 0.25 → 0.60 (some backgrounds)
- 0.48 → 0.83 (hero images)
