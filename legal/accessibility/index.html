Accessibility Statement

Last updated: January 14, 2026

1. Our Commitment

Patient Analog is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply the relevant accessibility standards to make our biotech education platform inclusive.

We aim to conform to WCAG 2.1 Level AA standards.

2. Accessibility Features

Our website includes the following accessibility features:

Keyboard Navigation All functionality is accessible via keyboard
Focus Indicators Visible focus states for interactive elements
Alt Text Descriptive text for images and graphics
Semantic HTML Proper heading structure and landmarks
Color Contrast Text meets minimum contrast ratios
Responsive Design Adapts to different screen sizes and zoom levels

3. Assistive Technology Support

Patient Analog is designed to work with assistive technologies including:

  • Screen readers (NVDA, JAWS, VoiceOver, TalkBack)
  • Screen magnification software
  • Speech recognition software
  • Keyboard-only navigation
  • Alternative input devices

4. Technical Specifications

Accessibility of Patient Analog relies on the following technologies:

  • HTML5
  • WAI-ARIA
  • CSS
  • JavaScript

These technologies are relied upon for conformance with the accessibility standards used.

5. Known Limitations

While we strive for full accessibility, some limitations may exist:

  • Third-party content: External links to research papers, FDA databases, and other resources may have varying accessibility levels
  • Interactive simulations: Some educational simulations may have limited accessibility; we provide alternative text descriptions where possible
  • PDF documents: Some linked PDFs from external sources may not be fully accessible
  • Live data feeds: Real-time ticker and data displays may require screen reader optimization

6. Browser Compatibility

For the best accessible experience, we recommend using:

  • Chrome (latest version)
  • Firefox (latest version)
  • Safari (latest version)
  • Edge (latest version)

7. Feedback and Contact

We welcome your feedback on the accessibility of Patient Analog. Please let us know if you encounter accessibility barriers:

  • Email: accessibility@patientanalog.com
  • Contact form: Contact Page

We try to respond to accessibility feedback within 5 business days.

8. Assessment and Remediation

Patient Analog assesses accessibility through:

  • Automated testing tools (Lighthouse, axe, WAVE)
  • Manual testing with assistive technologies
  • User feedback and testing
  • Regular accessibility audits

We are committed to addressing accessibility issues promptly and improving our platform continuously.

9. Formal Complaints

Email: legal@patientanalog.com
